# CH DN Saiteja - Portfolio

Personal portfolio website for CH DN Saiteja.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features

- Responsive layout
- Modern dark theme
- Mobile navigation
- About section
- Skills section
- Projects section
- Contact section
- GitHub Pages compatible

## Run Locally

Simply open:

index.html

in any modern web browser.

## GitHub Pages

This project can be deployed using GitHub Pages.

Go to:

Repository → Settings → Pages

Select:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Then save.
